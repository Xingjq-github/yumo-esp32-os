# 密码本使用与维护

更新日期：2026-10-20。当前设备版本见[当前状态](../current-state.md)。PC/NAS服务与设备热点网页是两个入口，设备管理PIN与服务管理员密码相互独立。

## 分类与新增

| 分类 | 分组与详情 |
| --- | --- |
| 工作 | 先选“单位 / 系统”，再选条目 |
| 应用 | 先选“应用名称 / 平台”，再选条目 |
| 网页 | 先选账号，再查看用途及密码 |
| 其他 | 直接列条目；不展示账号，“密码”改为“码值”，在已进入的功能页面中持续明文展示 |

设备、PC服务和热点密码网页采用一致分类语义。空分组显示“未填写”，按原字段精确分组，不合并密码。PC服务新建/编辑工作或应用时，可下拉选择已有单位/系统或应用/平台，也可手动输入新分类。详情与编辑使用相同属性名称。

PC网页通过`packaging/pc/Status-Local.cmd`查询地址，管理员登录后可新建/编辑。全新部署设置4～128字符管理员密码；已有管理员继续使用原密码。普通密码编辑留空保留原值，其他类使用“码值”且不显示旧账号；旧账号兼容字段不因普通编辑被清除。

名称、用途和备注支持中文；蓝牙输入的账号/密码/码值限制为最多128个可打印ASCII字符，不支持中文或换行，保留首尾空格。全库最多256条；名称96、用途192、备注256个UTF-8字节，备注超长按字符边界截断。推荐密码默认16位，可选4～64位及字符集合，浏览器生成，保存后才入库。

## 设备界面与明文查看

首次打开设置4～12位数字PIN并确认。PIN页全屏，只有分类首页提供修改密码入口。拼贴主题将底部空余高度分配给上方三个功能按钮及两行分类按钮；列表按需复用控件。

单条详情的顶栏直接显示名称，下方不重复名称。账号和密码直接作为对应蓝牙输入按钮的内容；普通密码默认掩码，验证PIN后可临时明文，再次切换可隐藏。其余字段显示“用途：”“备注：”等属性标签。“其他”分类只显示码值及相关属性，不提供账号或隐藏开关。

设备超管验证PIN后开启全局明文；关闭、关屏、退出或空闲锁定后清理授权。普通明文有时限和离页清理规则，其他类码值持续展示不代表绕过进入密码本所需的管理验证。

“二维码”将当前条目的明文文本详情实时编码，普通密码需先取得明文授权。二维码包含UTF-8文本及属性标签，不是外部链接；不保存二维码图片。二维码页30秒超时，返回/锁定时清理文本和像素。内容过长而无法在小屏保持可扫码尺寸时明确提示，不截断密码。真实手机扫码效果仍需实测。

## 同步和蓝牙输入

同步需要Wi-Fi，不要求蓝牙；蓝牙用于向目标电脑或手机输入当前账号、密码/码值，回车单独发送，不自动追加。超管、单条展示与蓝牙私密输入继续要求各自的授权/安全连接。

服务端完整有效列表覆盖设备，包括删除及空列表；传输失败保留原库。设备本地地址失败后可从SD`config/vault.json`尝试一次，只有同步成功才保存新地址。密码文件位于独立vault分区，不放在SD；加密存储、同步身份和双方密钥保持原值。详见[同步说明](vault_sync_20260920.md)。

## 热点浏览器

打开局域网热点，手机连接该热点后访问设备显示的HTTP地址。密码入口输入与设备密码本相同的管理PIN，解锁后先显示工作、应用、网页、其他四个分类按钮，再进入上述分组查看明文并复制。该入口只读，不负责修改或向PC服务同步。

浏览器会话限时，主动锁定、切回文件页、页面隐藏/离开等会清理明文；关闭热点、退出局域网或深睡会停止服务。HTTP为明文传输，使用范围为设备热点。文件操作和访问地址说明见[局域网](lan_hotspot_20260920.md)。

## 改密、遗忘与迁移

设备改PIN需原PIN和两遍新PIN；服务端改管理员密码需原密码和两遍新密码，成功后其他登录会话失效，设备PIN与条目不变。设备没有忘记PIN的App内恢复入口。

确实遗忘时，先确认网页管理员能登录、完整列表可恢复，并备份设备数据，再单独授权初始化设备PIN及本地密码缓存。不能在编译、同步源码或蓝牙修复时顺带清库，也不应重建身份或清空整个NVS。2026-10-09的设备初始化属于已完成维护，不重复执行。

全分类支持加密`.jyvault`导出、预览和去重合并导入，需同一部署密钥；与设备全量覆盖同步不同，见[加密迁移](vault_archive_20260918.md)。Edge CSV只支持网页分类，含预览/跳过报告、同账号密码合并、UTF-8备注截断与版本冲突检查，见[CSV导入](vault_csv_import_20260918.md)。

服务构建与启停见[PC说明](../server/pc.md)，NAS见[部署说明](../server/nas.md)。当前状态不能由旧IP/PID推断，升级源码不自动启动或部署服务。密码分区读取/内存/校验错误应分别处理，不能将失败当空库覆盖。
