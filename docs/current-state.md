# 当前功能基线

版本基线：2026-10-22。目标板为ESP32-S3-Touch-LCD-1.54。完整功能见[应用总览](firmware/overview.md)，构建方法见[构建说明](build.md)。

## 主要能力

- 24个按需加载的应用，五套主题、统一四向旋转及应用方向锁定。
- MP3/LRC播放页、记录上次曲目、独立解码/音频任务；本机扬声器输出。
- IINE-1001/L1162的C模式控制FC，H模式用于方向选择、A确认、B返回及时钟左右翻页；各地址独立保存，8条安全配对、同时一个连接。
- FC输出240×240居中1:1像素，原帧左右各裁8列；保留半速显示的相位调度、35种Mapper、手动与自动存档。
- 密码本分类/二维码、Java网页服务、热点内的SD硬盘及只读密码网页。
- 图片视口解码和SD分块缓存、秒表动态分段、萌芽物语养成、测速图表及SD历史。
- Wi-Fi按上游状态自动共享、内部RTC校时学习与离线补偿、电量曲线与省电策略。

## 当前边界

Type-C耳机和USB有线键盘功能不在此版本中；USB读卡器、投屏与开发串口保留。没有OTA入口；蓝牙媒体遥控不等于A2DP音频输出。图片16MiB为输入上限，仍有像素和内存预算。标准板没有独立RTC晶体，完全断电后需重新校时。

MP3长期听感、最新H模式交互、全部ROM/FC实际帧率、SD长期稳定性和RTC学习后残差仍需针对硬件测试。检查口径及已执行范围见[验证说明](validation.md)。

每次克隆使用自己的初始化配置。来源固件的启动检查不能代替新配置下的完整构建与设备验收。
