## 执行完整构建

按[构建文档](build.md)完成固定版本环境、组件、SDK补丁及[初始化](configuration.md)，然后执行：

```bat
Build.cmd
Build-Server.cmd
```

完整固件入口生成资源、编译固件并执行检查与目标模型。只运行源码检查、某个模型或编译阶段，不代表其余阶段通过。

## 可选宿主回放

GCC/G++加入PATH后，可使用独立的新输出目录：

```bat
python -B tooling\firmware\test_ble_gamepad.py --run-dir artifacts\validation\ble-gamepad-local
python -B tooling\firmware\test_ble_peer_store.py --run-dir artifacts\validation\ble-peer-store-local
python -B tooling\firmware\test_clock_drift_runtime.py --run-dir artifacts\validation\clock-local
```

MP3、图片和界面回放还需各脚本声明的依赖与夹具，使用`--help`查看参数。FC旧/新渲染对照需要显式提供历史基线；历史本地基线没有混入当前源码。

## 实机验证

烧录后分别确认触控/按键、蓝牙模式、USB/SD所有权、应用退出及电源收尾。游戏实际帧率、音质、长时间SD读写、完全放电和RTC学习后精度需要真实硬件测量，宿主耗时不等于ESP32性能。
